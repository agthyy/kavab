# Kavabanga Learning Platform (Академия профессиональных бариста)

Премиальная интерактивная платформа для обучения профессиональных бариста. Проект состоит из мобильного приложения, административной панели управления и бэкенд-сервиса.

---

## 🏗 Архитектура проекта

Репозиторий имеет монолитную структуру и разделен на три основных компонента:

*   **`mobile/`** — Мобильное приложение на **Flutter** (Dart) с современным кофейным дизайном в стиле Glassmorphism, геймификацией (опыт, уровни, Quest-системы, коллекции коллекционных карточек) и интерактивным деревом обучения.
*   **`admin/`** — Панель администратора на **Next.js** (TypeScript, TailwindCSS) для управления пользователями, редактирования курсов, тестов и настройки достижений.
*   **`backend/`** — REST API бэкенд-сервис на **Node.js / Express** (TypeScript) с СУБД **PostgreSQL** (Knex.js).

---

## ⚡ Основные возможности

1.  **Интерактивное обучение**: гибкие курсы с модулями, уроками и интерактивными тестами.
2.  **Ролевой доступ**: возможность ограничивать курсы и достижения по должностям (бариста, официант, менеджер и др.).
3.  **Геймификация**:
    *   Личные уровни и XP (опыт).
    *   Серии ежедневного посещения (Streak).
    *   Система редких, эпических и легендарных достижений.
    *   Разблокировка титулов и коллекционных карточек.
4.  **Управление персоналом**: создание, редактирование и безопасное удаление сотрудников через панель управления.

## 🚀 Быстрый старт

### 1. Бэкенд (backend)
Для запуска бэкенда убедитесь, что у вас установлен PostgreSQL и создана база данных `kavabanga`.

```bash
cd backend
npm install
# Запуск миграций и сидов
npx knex migrate:latest --knexfile src/config/knexfile.ts
npx knex seed:run --knexfile src/config/knexfile.ts
# Запуск сервера
npm run dev
```
*Бэкенд будет доступен по адресу: `http://localhost:3000/api`*

### 2. Панель управления (admin)
```bash
cd admin
npm install
npm run dev
```
*Панель управления будет доступна по адресу: `http://localhost:3001` (Стандартный вход: `admin` / `admin123`)*

### 3. Мобильное приложение (mobile)
```bash
cd mobile
flutter pub get
flutter run
```
